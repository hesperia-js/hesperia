## Fixed implementation choices

- TypeScript 7, exact supported version pinned. Oxc JavaScript bindings with the compiler implemented in TypeScript. No Rust compiler core.
- One immutable compilation snapshot and shared module semantics for checking and generation. Authored TSX becomes virtual checking TypeScript, checked with TypeScript 7 native APIs. Preserve every authored expression and contextual type; map results to authored source.
- Normalize TypeScript through Oxc with JSX preserved and ESNext output. Parse normalized JS/JSX, lower into a versioned canonical Hesperia intermediate representation, generate fresh JavaScript syntax trees, print with esrap, lower browser syntax with Oxc, bundle with Bun. Compose maps through every stage. Errors prohibit executable emission even if a parser recovered code.
- Canonical meaning cannot contain tool syntax-tree objects, executable closures, or unanalyzed source fragments. Resolve expressions, declarations, captures, ownership, component slots and keys explicitly. Keep source/debug spans separate from semantic identity. Deterministic encoding and SHA-256 with named algorithm for this milestone.
- Reject HTML composition outside the profile whose browser parsing and namespace placement can be established. Test table/paragraph/template/raw-text and SVG/MathML contexts. Do not advertise full language coverage.
- Shared virtual-file implementation for CLI checker and minimal language service using Language Server Protocol, with VS Code client. Diagnostics, hover, completion and definitions map to authored TSX. Stock JSX.Element alone cannot give tag-specific native types. A supported jsx preserve configuration is required; custom hesperia-jsx mode is aspirational.
- Native JSX yields the actual native DOM object and exact type. Components accept caller props while body props expose the established accessor mapping; functions remain callable. Explicit accessor calls track Aeolia reads. No implicit raw-readable rendering.
- Awaited JSX waits for a child's render result, then the completed tree installs and effects run. Ordinary direct component calls remain forbidden. All async component uses need an enclosing async boundary. Only registered framework render awaits are accepted; no task dispatch/await in component bodies. Explicit ownership crosses async continuations.
- Package Aeolia as peer dependency with compatible local development dependency; do not ship duplicate reactive runtimes.

## Execution contracts

Component bodies normally execute once. When the reconciler identifies a concrete recoverable mapping condition, it may clean up the old lifetime and re-execute the body in a fresh lifetime. Prop/signal changes normally publish values and preserve DOM and state. No generic retry for exceptions.

Aeolia observer additions must permit explicit track/check/dispose, notification-only invalidation, a post-propagation handoff before the outer write returns, dynamic dependency replacement, equality-aware checks, and preservation of self-writes during evaluation. Do not change computed-value semantics to imitate effects.

Represent owners explicitly with lifecycle states, generation, abort/publication capabilities, logical identity and registered resources. Document graph ownership is separate from component lifetime. Each independent signal write updates DOM synchronously. Effects run after DOM in a microtask: descendants before ancestors, branches in rendered order, own effects in registration order. A later invalidation after an effect's turn goes to the next pass. Cleanup parent first, then descendant destruction, parent destruction last. Cleanup registrations run in reverse order; reads are untracked, writes forbidden, errors aggregate without stopping teardown. Faults reach nearest boundary then root.

Reconciliation validates one snapshot of incoming prop entries before publication and reuses it for recovery. Missing optional input publishes undefined; missing required input faults. First recreation allowed, second warns and proceeds, third faults before recreation in one connected Hesperia render frame. Initial mount excluded; stable slot/key counters survive new generations and microtasks. Preserve separate pass-limit protection.

Bindings: explicit generic types; creator callable readonly; child receives writable endpoint through reserved bind attribute. Component.Props supplies optional unknown bind unless author refines it. Required reads while empty fault and body reads are prohibited, including after await. Validate first publication by end of first effect pass for mounted parent/children. Duplicate target, stale setter and invalid loss fault. Replacement never publishes undefined; moves preserve binding. Creator teardown permits target removal. Guard retained component methods after destruction; native methods retain browser behavior. Check continued external removal after mutation observation, allowing same-tree synchronous remove/reinsert. Required bind passed to independently loading async child immediately faults; awaited composition is supported without boundary forwarding. unsafeBind permits absence and warns.

Queries: follow the latest query failure and revalidation revision in the design reconciliation. Return a live accessor for usable data (including stale data and valid undefined), and revalidate when no request is running. An existing failed status rejects the await with its status and error and permits one recovery attempt, whether or not committed data existed. Recovery is shared by graph and query key. Successful recovery re-arms the revalidation timer and restores the recovery allowance for a later failure; failed recovery faults and stays disarmed until explicit author retry. Raw Aeolia ready remains unchanged. Owner removal immediately rejects its wait; the shared request may finish and publish. The earlier no-dispatch rule is superseded. Exact rejection shape and adapter integration still require verification.

Tasks: factory per invocation receives fresh signal. Controller run/value/pending/error/status is not thenable. run returns per-invocation awaitable handle with id/signal/cancel for sync and async work. New invocation immediately cancels old, clears value/error, rejects old wait; late old results cannot publish. Cancellation is not ordinary error/boundary failure. Await resolves the specific invocation output. Preserve fire-and-forget observation semantics. No separate result waiter. Hesperia adapters convert Aeolia mutations into task controllers without changing raw Aeolia mutation returns.

Streams: add compatible projections consuming one shared source per key, with independent per-consumer projection state and every logical emission (even equal values). Preserve existing independent projection API. Activate after browser commit. Final listener departure starts collection deadline; incoming emissions cannot renew it. Returning listener resets the unobserved period. Collection ends subscription, requests cancellation, rejects late publication, uses Aeolia GC configuration. Query final-viewer policy differs intentionally.

Routing: filesystem page/layout/loading/error/not-found and parameter conventions from applicable RFC. Client-safe referenced guard extraction only from route declaration; no browser request-time loader execution. Latest navigation supersedes pending intent, incoming guards precede departure checks, veto/cancellation prevents installation. Terminal history/focus/scroll/title/announcement effects only after commit. Changed params remount; query updates use readonly Hesperia reactive projection, not native readonly URLSearchParams. History API supports baseline navigation.

Raw HTML: project-wide enable flag defaults false, disabled usage build/linter error. Unsafe insertion owns opaque region; changes delete root and subtree and create replacement. Second replacement of same logical region/frame warns; initial insertion excluded, count alone does not fault. All unsafe calls warn in browser and dev console. Preserve platform Trusted Types enforcement; no implicit sanitizer/trust policy.

Commands: init only empty destination; dev with full reload; build; preview and dev deep-link fallback; check via Hesperia checking. Ship browser assets without compiler. Editor integration uses shared TS7 checking views and suppresses duplicate stock diagnostics for its owned files.
